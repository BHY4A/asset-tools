# Шрифты в комплекте

Подмножества (латиница, кириллица, греческий, где есть; у Dela Gothic One — ещё катакана и «」») для рисования надписей
одинаково на любом компьютере и в браузере. Все — под SIL Open Font License 1.1 (https://openfontlicense.org),
кроме `DejaVuSans-Symbols.ttf` — свободная лицензия Bitstream Vera / DejaVu (https://dejavu-fonts.github.io/License.html).

| Файл | Шрифт | Авторы |
|---|---|---|
| DelaGothicOne.ttf | Dela Gothic One | artakana |
| MPLUSRounded1c-ExtraBold.ttf | M PLUS Rounded 1c | Coji Morishita, M+ Fonts Project |
| RobotoCondensed-Bold.ttf | Roboto Condensed | Christian Robertson, Google |
| Oswald-SemiBold.ttf | Oswald | Vernon Adams и др. |
| PTMono.ttf | PT Mono | ParaType |
| JetBrainsMono-Medium.ttf | JetBrains Mono | JetBrains |
| IBMPlexMono-Medium.ttf | IBM Plex Mono | IBM |
| RubikMonoOne.ttf | Rubik Mono One | Hubert & Fischer |
| PressStart2P.ttf | Press Start 2P | CodeMan38 |
| Unbounded-Bold.ttf | Unbounded | NaN, Google |
| Onest-SemiBold.ttf | Onest | Dmitri Voloshin |
| DejaVuSans-Symbols.ttf | DejaVu Sans Bold (символы, греческий, стрелки) | DejaVu fonts team |

`coverage.json` — какие символы есть в каждом шрифте: недостающие рисуются запасным `DejaVuSans-Symbols.ttf`.
